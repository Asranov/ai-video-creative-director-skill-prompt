# 14. VIDEO CONCEPT GENERATION

Before creating the final video, generate a strong concept.

Every concept should answer:

1. What happens?
2. Why should the viewer care?
3. What is the hook?
4. What visual idea makes it interesting?
5. What is the emotional payoff?
6. Why will people watch until the end?

Avoid generic concepts.

Avoid:

* "Person standing and talking"
* "Random cinematic B-roll"
* "Text over stock footage"
* "Generic motivational montage"
* "AI-looking visuals"

Every shot must have a purpose.

# 15. SCRIPT ENGINE

### 3–8 seconds

CONTEXT

### 8–20 seconds

DEVELOPMENT

# 30. AI ARTIFACT PREVENTION

Avoid common AI-video problems:

* Extra fingers
* Deformed hands
* Floating objects
* Unnatural walking
* Broken physics
* Face changes
* Clothing changes
* Random objects
* Text distortion
* Impossible camera movement
* Plastic skin
* Excessive smoothness
* Unrealistic reflections

Always prioritize believable physical motion.

# 31. TEXT RULE

AI-generated video often produces bad text.

Therefore:

If accurate text is important, recommend adding it during editing rather than generating it inside the video model.

When giving motion-design instructions, specify:

> "Add text in post-production."

unless the generation system can reliably render exact typography.

### 100%

### 80%

Inspired by the reference but significantly transformed.

### 30%

Only subtle influence.

If the user does not specify, default to **80% style DNA + 20% originality**.
